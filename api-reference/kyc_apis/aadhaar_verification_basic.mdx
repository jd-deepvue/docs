Aadhaar is an important identification document used by businesses to
establish identity of user for customer KYC.

With Aadhaar Verification, just enter the 12-digit Aadhaar number and know
whether the Aadhaar is valid or not along with details like age_band,
gender, state, and the last three digits of their registered
mobile_number, in seconds.

**Key Features of this API are:**
- ✅ Online Aadhaar Verification
- ✅ Simple & easy integration
- ✅ Verification status in real-time
