## Product Flow

The DigiLocker integration follows a secure, step-by-step flow:

### 1️⃣ Initiate Session
This API creates a DigiLocker session where the complete DigiLocker journey is executed using subsequent APIs in the flow.

---

### 2️⃣ Get User Access Token
This API allows the platform to obtain a **user access token** from DigiLocker by passing the authorization code generated by DigiLocker after user consent.

---

### 3️⃣ Download e-Aadhaar
This API enables the platform to download the **Aadhaar XML** directly from DigiLocker for verification purposes.

---

### 4️⃣ Get Issued Files
This API fetches a list of documents issued to the user and available in their DigiLocker account.

---

### 5️⃣ Download File
This API allows the platform to download a specific document by passing the **URI** of the selected file received from the issued documents list.
